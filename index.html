🤖 Thurbox

A TUI agentic IDE. Run Claude Code, Codex, opencode, aider — or any CLI agent you define — side by side in persistent tmux panes that survive crashes and restarts.

  • Sessions, agents and git worktrees as first-class citizens
  • Built-in MCP server so agents can drive Thurbox itself
  • SQLite-backed state, extensions for Jira, Linear, GitHub & more
